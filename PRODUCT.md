# Product

## Session flow

1. Choose topic: daily life / work / travel / free talk
2. Choose level: A2 / B1 / B2
3. Tutor starts with a short spoken question
4. User answers by voice
5. Screen shows four cards:
   - You said
   - Better English
   - One tip
   - Tutor question (audio autoplay)
6. Repeat for 8–12 turns (5–8 minutes)
7. End screen: 3 takeaways + 1 phrase to reuse tomorrow

## Teaching style

Kind, short, specific.

Bad: "Your grammar is wrong in several places. Let’s review present perfect."
Good: "Say **I went** instead of **I go**. Try it in the next sentence."

Korean notes are allowed on screen. Spoken tutor stays in English.

## Metrics that count as "성과"

Pick numbers you can screenshot on a resume.

### Learner metrics
- Sessions completed / week
- Speaking minutes
- Unique phrases produced
- Recurrence: same error type down over 2 weeks
- Target-phrase reuse rate (did they actually say the corrected form later?)

### Product metrics
- Time-to-first-reply
- Turn completion rate (did they answer the follow-up?)
- Session finish rate (started vs completed 8 turns)

### Demo metrics (even with only you as user)
- 14-day personal log
- Before/after samples of the same prompt
- Error taxonomy chart (tense / article / preposition / word choice)

A 2-week self-experiment is enough for a portfolio case study if you log it cleanly.

## Case study outline (for README or Notion)

1. Problem: I avoided speaking English
2. Constraint: no human tutor, needed correction without shame
3. Build: speech loop + structured tutor JSON + history
4. Test: 10 sessions on one topic
5. Result: e.g. past-tense errors dropped, answers got longer
6. Next: streaming STT, pronunciation highlight

Keep claims honest. “I used it for 10 sessions and past-tense mistakes fell” is better than “AI English teacher.”
