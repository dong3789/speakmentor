# Roadmap

## Phase 0 — Record (today)
- Product one-pager
- Architecture
- Tutor JSON schema
- Resume one-liner

Done in this folder.

## Phase 1 — Ugly but real MVP (3–7 days)
Must have:
- Web record button
- Upload audio
- STT → LLM JSON → TTS
- Session saved
- History page with transcripts

Skip pretty UI. One column is fine.

Demo bar: a stranger can open the URL, talk, and hear a reply.

## Phase 2 — Tutor quality (3–5 days)
- Level memory
- One-error-per-turn rule
- Force reuse of target phrase
- Korean coach note + English audio split
- Simple stats: minutes, turns, top error type

This is the difference between a wrapper and a product.

## Phase 3 — Evidence (1–2 weeks of use)
- You are the first user
- Same 5 prompts every 3 days
- Save audio + transcripts
- Write a short case study with charts

This is what you put on the resume under “Impact.”

## Phase 4 — Optional polish
- Streaming STT
- Waveform + highlighted words
- iOS wrapper
- Shadowing mode (listen and repeat)
- Export weekly report PDF

Only after Phase 3 has numbers.

## Resume lines you can earn

After Phase 1:
- Built a voice-in / voice-out English tutoring web app (STT + LLM + TTS)

After Phase 2:
- Designed a constrained tutoring policy and structured evaluation schema for learner utterances

After Phase 3:
- Ran a 2-week self-study experiment and tracked error types / phrase reuse across sessions
